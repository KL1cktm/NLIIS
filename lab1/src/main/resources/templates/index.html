Как пользоваться поиском

1. Ввод запроса: Введите слова для поиска в текстовое поле.

2. Поиск: Нажмите кнопку "Найти" для получения результатов.

Система автоматически ищет по всем текстовым файлам (с расширением .txt), находящимся в папке `documents` и всех ее подпапках.

Поиск является "умным": он учитывает различные формы слов (падежи, числа), поэтому вы можете вводить запросы на естественном языке.
